## Befunde, nicht sperrend

1. `betrieb_status` in `app/main.py` liest das modulprivate `backup._letztes_ergebnis`. Kosmetik, bei P30/P31-Anbindung des Betriebsstatus in eine öffentliche Funktion ziehen.
2. Das letzte Ergebnis lebt nur im Prozessspeicher. Nach einem Neustart zeigt der Status bis zur ersten Sicherung den alten Existenz-Check. Für die Testinstanz ausreichend; vor M6 im Manifest persistieren.
3. `manifest_ok` verlangt jetzt null fehlende Belege. Ein Tag mit einem fehlenden Beleg gilt damit als nicht gesichert, wie von der Karte gewollt. Der Nutzer muss das im Betriebsstatus sehen können (P30-Schuld A6/§10 bleibt).
